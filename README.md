# Samagram Technologies — Dark Theme Website

A modern, responsive React + Vite + Tailwind CSS homepage for **Samagram Technologies Private Limited**.

## How to Install & Run

1. Extract this ZIP folder.
2. Open the extracted folder in VS Code (or terminal).
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the local development server:
   ```bash
   npm run dev
   ```
5. Open the URL shown in the terminal (usually `http://localhost:5173`).

## Project Structure
- `src/components/Navbar.jsx` & `navbar.css` — Sticky glassmorphism navigation bar with custom SVG brand logo & mobile menu.
- `src/components/Home.jsx` & `home.css` — Hero section, real-world photography, stats, about, 6 services, filterable projects with detail modal, industries marquee, 4-step process, and contact enquiry form.
- `src/components/Footer.jsx` & `footer.css` — Professional multi-column agency footer with newsletter signup, quick links, services, contact info, live IST clock, and back-to-top button.
